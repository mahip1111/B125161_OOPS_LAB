# OOP Laboratory Lab 7 – Inheritance

Based on the IIIT Bhubaneswar OOP Laboratory Lab 7 sheet (06.10.2026, Group B2).

## Programs

1. Employee Salary – Multilevel Inheritance
2. Student Result – Function Overriding
3. Vehicle Rental – Multilevel Inheritance
4. Banking System – Hierarchical Inheritance
5. Student Performance – Multiple Inheritance
6. Resolving Ambiguity in Multiple Inheritance
7. University Personnel – Hybrid Inheritance
8. Hospital System – Protected Members
9. Constructor Execution in Inheritance
10. Diamond Problem – Virtual Inheritance

## Compile

For example:

```bash
g++ 01_Employee_Salary_Multilevel.cpp -o program
./program
```

Repeat the same pattern for the other `.cpp` files.

## Notes

- Each program is standalone.
- Constructors are used where required.
- The inheritance structures follow the lab sheet.
- Virtual inheritance is used in Problems 7 and 10.
- Scope resolution is used to resolve the ambiguity in Problem 6.
